# Vibe Refactor (refactor)

운영 중인 서비스를 안전한 순서로 리팩토링하는 Claude Code 플러그인입니다.

- `/refactor:go` — 준비 → 코드 지도 → 25항목 건강검진 → 정밀검사 → 반박 검증 → 기준선 → 계획서 → 승인된 단계를 차례로 이어서 실행(한 단계씩은 `/refactor:go 하나씩`)
- `/refactor:approve` — 기준선 계획·계획서 단계 승인, 기준선 허용, 작업 가지 push 허락(`푸시`), PR 합치기 허락(`합치기`), 합친 뒤 새 작업 가지(`새 가지`) — 사용자만
- `/refactor:status` — 이 프로젝트 현황
- `/refactor:board` — 여러 프로젝트 현황표
- `/refactor:report` — 문제 신고(진단 묶음을 먼저 보여 주고 동의하면 GitHub 이슈로, 사용자만)

읽기 단계는 자동으로 이어 가고, 코드를 바꾸는 단계는 승인된 것만 하나씩 차례로 합니다(단계마다 검사·커밋)(승인의 근거는 `docs/refactor/APPROVALS.log`, 사용자가 입력창에 `/refactor:approve`를 치면 입력 훅이 승인을 처리하고, Claude가 승인 스크립트를 부르는 것은 막힙니다 — 따옴표로 이름을 쪼개거나 새 Claude 세션에 넘기는 것 같은 알려진 우회 모양도 막습니다). 테스트·빌드는 운영 키 대신 가짜 값을 넣는 안전 실행기로 돌립니다. 리팩토링 중에는 안전장치 훅이 비밀값 노출·되돌릴 수 없는 명령·승인 우회 같은 흔한 사고를 미리 막습니다(모든 우회를 막는 벽은 아님).

설치·사용법·안전장치 설명은 저장소 맨 위의 [README](../../README.md)를 보세요.
