# Vibe Refactor (refactor)

운영 중인 서비스를 안전한 순서로 리팩토링하는 Claude Code 플러그인입니다.

- `/refactor:go` — 준비 → 코드 지도 → 25항목 건강검진 → 정밀검사 → 반박 검증 → 기준선 → 계획서 → 승인된 단계를 하나씩 실행
- `/refactor:approve` — 기준선 계획·계획서 단계 승인(사용자만)
- `/refactor:status` — 이 프로젝트 현황
- `/refactor:board` — 여러 프로젝트 현황표

읽기 단계는 자동으로 이어 가고, 코드를 바꾸는 단계는 승인된 것만 한 번에 하나씩 합니다(승인의 근거는 `docs/refactor/APPROVALS.log`). 테스트·빌드는 운영 키 대신 가짜 값을 넣는 안전 실행기로 돌립니다. 안전장치 훅이 비밀값 노출·되돌릴 수 없는 명령·승인 우회 같은 흔한 사고를 미리 막습니다(모든 우회를 막는 벽은 아님).

설치·사용법·안전장치 설명은 저장소 맨 위의 `README.md`를 보세요.
