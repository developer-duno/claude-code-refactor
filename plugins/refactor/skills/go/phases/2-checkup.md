# 2단계: 종합 건강검진 (CHECKUP)

목표: 제품 코드를 4영역 25항목 신호등으로 진단하고, 무엇부터 막고 어떤 정밀검사를 할지 정해 `docs/refactor/AUDIT_REPORT.md`에 남긴다.

## 1. 셸이 필요한 검사는 먼저 네가 돌린다 (보조 AI는 셸이 없다)
값이 화면에 찍히지 않는 명령만 쓰고, 결과를 "셸 검사 결과"로 정리해 보조 AI에게 넘긴다.
- `.env` 추적 여부: `git ls-files | grep -E '(^|/)\.env'` (이름만), `git check-ignore -v .env .env.local .env.production`
- 과거 커밋 속 비밀값: 접두어마다 `git log --all --oneline -S "<접두어>"` — 예: `sk_live`, `sk_test`, `live_sk`, `test_sk`, `sb_secret_`, `service_role`, `eyJhbGciOi`, `AKIA`, `ghp_`, `github_pat_`, `xoxb-`, `AIza`, `-----BEGIN` (커밋 번호만 나온다. `-p`나 `| grep`은 절대 붙이지 않는다 — 안전장치도 막는다)
  - Supabase: 새 비밀 키는 `sb_secret_`로 시작한다. 옛 `service_role` 키 값은 `eyJ`로 시작하는 긴 문자열(JWT)이라 `service_role` 글자로는 못 찾는다 — `eyJhbGciOi`로 찾은 커밋은 "비밀값 후보(확인 필요)"로 적는다(공개용 anon 키도 같은 모양이다).
- 원격 저장소: `git remote` (이름만) 와 `git remote -v | sed -E 's#//[^/@]*@#//****@#'` (주소 속 토큰은 가림)
- 최근 커밋 날짜·브랜치: `git log -1 --format=%cd`, `git branch --show-current`
- 큰 파일·고객 데이터 파일이 올라갔는지: `git ls-files | grep -Ei '\.(csv|xlsx|xls|sql|dump|bak|zip)$'` (이름만)

## 2. 보조 AI 4명을 동시에 (한 메시지에서 Agent 도구 4번)
- `refactor:auditor` × 4 — 각자 `${CLAUDE_SKILL_DIR}/checklists/checkup.md`의 영역 하나(A 돈·개인정보·법 / B 안 끊기게 / C 고치기 쉽게 / D 손님 화면)만 맡는다.
- 각자에게 줄 것: 점검표의 실제 전체 경로, 맡을 영역, PROFILE.md 요약, PROJECT_MAP.md 경로, 위 셸 검사 결과, "결과 4,000자 이내, 점검표의 표 형식 그대로".

## 3. 합치기 전에
- 🔴 판정은 **전부** 네가 그 파일:줄을 직접 열어 확인한다. 다른 곳(미들웨어·DB 제약·상위 함수)에서 이미 막고 있으면 판정을 고치고 이유를 적는다.
- 빈칸·"문제 없음"만 있는 행은 근거를 요구한다. 근거가 없으면 ⚪ 미점검.

## 4. AUDIT_REPORT.md 형식
1. **한 줄 총평** (비유 하나)
2. **리팩토링 준비도**: 🟢 바로 시작 가능 / 🟠 안전망(백업·기준선)부터 / 🔴 구멍부터 막고 시작
   - A영역에 🔴가 하나라도 있으면 🔴
   - A영역에 ⚪가 있으면 최고 🟠
   - B4(백업)나 C1(테스트)이 🔴 또는 ⚪이면 최고 🟠
   - ⚪가 5개 이상이면 최고 🟠
3. **25항목 신호등 표**: `| 코드 | 항목 | 상태 | 근거(파일:줄) | 확신도 | 방치하면 생기는 일 | 정밀검사 점검표 | 검증 |` (검증 칸은 4단계에서 채운다)
4. **★ 지금 당장 막아야 할 것** (🔴, 최대 5개): 무엇이 / 왜 위험한가(사업 관점) / 사람이 지금 할 일 / 확신도
5. **정밀검사 목록** (3단계 입력): 어떤 점검표를 왜 돌리는지
6. **나에게 확인할 질문** (코드에 없는 것, 예/아니오로, 최대 7개)
7. **이번 검진의 한계**
8. **셸 검사 결과** — 1에서 돌린 명령과 결과 요약(값 없이 이름·개수·커밋 번호만). 정밀검사 단계가 `/clear` 뒤에도 이 결과를 쓸 수 있게 남긴다.

## 5. 치명적 발견은 즉시 알린다
비밀 키가 공개 저장소에 올라감, 로그인 없이 전체 주문·개인정보가 보임, 결제 금액을 화면 값 그대로 믿음 같은 발견은 자동 진행 중이라도 사용자 보고 맨 위에 올리고 "지금 사람이 할 일"을 먼저 말한다.
