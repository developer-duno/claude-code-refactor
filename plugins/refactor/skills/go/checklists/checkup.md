# 점검표: 종합 건강검진 25항목 (CHECKUP)

지휘자가 맡긴 **묶음 하나만** 점검한다. 항목마다 "방치하면 무슨 사고가 나는지"까지 본다.
상태는 🔴 위험 / 🟠 주의 / 🟢 양호 / ⚪ 미점검 / — 해당 없음 중 하나. **🟢에도 근거가 있어야 한다.** 미확인은 안전이 아니다.

## A. 돈·개인정보·법 (터지면 되돌릴 수 없는 것)
- **A1 접근 권한** — 관리자 화면·API가 서버에서 로그인·권한을 확인하나? 요청의 번호(주문·회원·매물 id)만 바꾸면 남의 데이터가 보이나? 브라우저가 DB에 직접 붙는 구조(Supabase·Firebase 등)면 공개 테이블마다 행 단위 보안(RLS·보안 규칙)이 켜져 있고, 전체 허용 정책은 아닌가?
- **A2 입력 검증** — 화면에서만 검사하고 서버는 그대로 믿나? 손님이 쓴 글(메모·요청사항·리뷰)이 관리자 화면에 HTML로 그대로 찍히나? SQL을 문자열로 이어 붙이나?
- **A3 비밀값** — 코드·설정·git 기록, 브라우저로 내려가는 공개 변수(`NEXT_PUBLIC_`·`VITE_` 등)에 비밀 키가 있나? `.env`가 git에 추적되나(`.env.example`은 정상)?
- **A4 결제·주문** — 결제 금액을 서버가 DB 값으로 다시 계산하고, 결제사가 정한 방식으로 실제 결제 금액과 대조하나? 결제사 알림(웹훅)을 두 번 받아도 주문이 한 번만 생기나? 결제는 됐는데 주문 저장이 실패하면?
- **A5 개인정보 취급** — 목적보다 많이 받나? 로그·운영자 알림방·오류 메일에 전화번호·주소가 그대로 찍히나? 보관 기간·파기 로직이 있나?
- **A6 법규 표시·동의** — (판매하는 서비스) 사업자 정보·약관·개인정보 처리방침·환불 안내가 화면에 있나? 마케팅 수신 동의가 필수 동의와 분리돼 있나? 업종별 표시 의무(예: 부동산 중개 광고)가 있나? — "위반"이라고 쓰지 말고 "누락 후보"로.
- **A7 수집 데이터의 권리** — 다른 회사 사이트의 데이터를 대량·반복으로 가져와 그대로 게시하나? 차단을 피하려는 코드(IP 돌리기·캡차 우회·로그인 우회)가 있나?

## B. 안 끊기게 (장사가 조용히 멈추지 않게)
- **B1 에러 처리** — 에러를 삼키는 코드(빈 catch/except, 실패했는데 "성공" 응답)가 있나?
- **B2 외부 호출** — 결제·문자·지도·수집 대상 같은 바깥 호출에 타임아웃·재시도 상한이 있고, 재시도해도 두 번 처리되지 않게(멱등) 돼 있나?
- **B3 알림** — 주문 실패·결제 불일치·발송 실패·수집 0건을 운영자가 손님보다 먼저 알 수 있는 경로(휴대폰 알림 등)가 있나?
- **B4 백업·복구** — DB 백업 설정이 코드·설정에서 보이나? 복원 절차 문서가 있나? (요금제에 따라 자동 백업이 없을 수 있음 — 코드에 없으면 ⚪ + "사람에게 확인")
- **B5 데이터 정합성** — 중복을 막는 고유 제약, 여러 테이블을 연달아 바꿀 때 트랜잭션, 주문 상태가 여러 파일에서 제각각 바뀌는 곳.
- **B6 구조 변경 이력** — DB 구조 변경이 마이그레이션 파일로 남아 있나, 코드와 스키마가 어긋난 흔적이 있나?
- **B7 수집 파이프라인** — 매번 전체를 다시 받나? 실패가 조용히 0건으로 저장되나? 요청 간격·동시 요청 수 제한, 중복 제거 기준이 있나?

## C. 고치기 쉽게 (다음 수정이 무섭지 않게)
- **C1 테스트 안전망** — 테스트가 있나? 돈 계산·주문·수집·매칭 같은 핵심 흐름을 덮나? 실행 명령은?(정의만)
- **C2 중복·죽은 코드·매직넘버** — 특히 금액·배송비·수수료 계산이 여러 곳에 따로 있나? 1,000줄 넘는 파일은?
- **C3 환경 분리** — 개발과 운영의 DB·키가 분리돼 있나? 테스트 결제 키와 운영 결제 키, 개발 중 실제 고객에게 문자가 나갈 위험은?
- **C4 의존성** — lock 파일, 지원이 끝난 런타임·패키지 정황.
- **C5 배포·되돌리기** — 배포 방식, 배포 전 자동 검사, 되돌리는 방법, 원격 저장소 백업.
- **C6 비용** — 같은 외부 API 반복 호출, 무한 재시도, 오래 도는 서버리스 함수.
- **C7 문서·AI 규칙** — 실행법(README), AI 규칙 파일(CLAUDE.md 등)이 있고 코드와 맞나?

## D. 손님 화면 (찾아오고, 쓰기 쉽게)
- **D1 검색 노출** — 페이지별 제목·설명, sitemap, robots.txt(네이버 `Yeti`·`Googlebot`을 막지 않나), 상품·매물 상세가 서버에서 그려지나?
- **D2 접근성·모바일 폼** — 이미지 대체텍스트, 입력칸 label, 전화번호 칸 `type="tel"`, 결제·주문 버튼 연타 방지.
- **D3 느려 보이는 정황** — 재지 말고 정황만: 크기 없는 큰 이미지, 긴 목록을 한 번에 그림, 같은 요청 반복.
- **D4 시간대** — 서버 시간이 UTC(= 세계 표준시, 한국보다 9시간 느림)인데 마감·예약·당일 처리를 한국시간으로 계산하나?

## 출력 형식 (맡은 묶음만)
| 코드 | 항목 | 상태 | 근거(파일:줄) | 확신도 | 방치하면 생기는 일 |

그 아래에:
- **🔴 상세** — 🔴마다: 근거 코드 발췌(최대 5줄, 비밀값은 ****) / 왜 문제인지 / 이미 다른 곳에서 막고 있지 않은지 찾아본 결과
- **"없다"고 판정한 항목의 검색 근거** — 어떤 패턴으로 어디를 검색했는지
- **사람에게 확인할 것** — 코드에 없는 것(대시보드 설정, 요금제, 운영 키 위치 등)
