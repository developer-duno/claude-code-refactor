# 정밀 점검표: 필수 표시·동의 (법규 누락 찾기)

기능이 잘 돌아가도 화면에 있어야 할 사업자 정보·약관·동의가 빠지면 과태료나 시정명령을 받을 수 있다. AI가 만든 사이트는 하단 정보가 템플릿 그대로이거나, 개인정보 처리방침이 실제로 받는 정보와 맞지 않는 경우가 많다.

## 이 점검의 안전 규칙 (너는 변호사가 아니다)
- **법률 판단 금지.** "위반이다 / 합법이다"라고 쓰지 않는다. 상태는 있음 / 누락 후보 / 일부 / 미확인 / 해당 없음, 그리고 **확인할 원문 이름**만 적는다.
- 조항 번호는 확실할 때만. 헷갈리면 법령·고시 이름만. 법령은 바뀌므로 "실행 시점 원문 확인"을 붙인다.
- 법령 내용·과태료 금액을 기억으로 인용하지 않는다.
- 문구를 확정하지 않는다. 초안은 "원문·전문가 확인 전 게시 금지"를 붙여 보고서에만 두고, 사이트 파일에 넣지 않는다.
- 사업자 정보는 있음/없음만 적고 값을 옮겨 적지 않는다.
- 화면에서 못 찾았다고 "없다"고 단정하지 않는다. 어떤 파일·문구로 검색했는지 적고 "누락 후보"로 둔다.

## 먼저 파악
서비스 종류(판매·예약·중개·구독·콘텐츠·무료), 결제·회원가입 유무, 받는 개인정보(코드의 입력 필드·DB 컬럼), 광고성 메시지(알림톡·문자·이메일·푸시) 발송 여부, 개인정보를 맡기는 곳(결제사·문자 발송사·호스팅·분석 도구)과 해외 서버 여부, 업종별 특별 규정 분야(부동산 중개·식품·건강·의료·금융).

## 점검 항목 (괄호 안은 확인할 원문 예시)
- **CO1 사업자 정보 표시**(판매하는 경우) — 상호·대표자·주소·전화·이메일·사업자등록번호·통신판매업 신고번호·호스팅 제공자·이용약관이 모든 페이지 하단이나 첫 화면에서 보이나? (전자상거래법의 사이버몰 운영자 표시 규정, 공정거래위원회 '전자상거래 등에서의 소비자보호 지침')
- **CO2 구매 전 안내** — 반드시 내야 하는 총액(배송비 등 포함)이 **가격을 처음 보여 주는 화면부터** 보이나? 배송·제공 시기, 교환·환불(청약철회) 조건과 제한 사유(주문 제작·신선 상품 등)가 결제 전에 보이나? (전자상거래법의 청약철회 규정과 다크패턴 관련 규정 — 2025-02-14 시행분 포함)
- **CO3 개인정보 처리방침** — 모든 페이지에서 찾기 쉬운 링크가 있나? 적힌 수집 항목·목적·보관 기간·맡기는 곳(수탁자)·해외 이전이 **코드가 실제로 받는 필드·연동과 맞나**? (개인정보 보호법, 개인정보보호위원회 '개인정보 처리방침 작성지침')
- **CO4 동의 받는 방법** — 필수와 선택 동의가 나뉘어 있나? 마케팅 수신 동의가 필수 동의에 묶였거나 미리 체크돼 있지 않나? (개인정보 보호법의 동의 방법 규정)
- **CO5 광고성 메시지** — 보내기 전에 수신 동의를 받나? "(광고)" 표시, 수신 거부 방법, 밤 시간대 발송의 별도 동의를 지키나? (정보통신망법의 영리 목적 광고성 정보 전송 규정)
- **CO6 탈퇴·파기** — 탈퇴 경로가 찾기 쉬운가? 탈퇴·보관 기간이 끝난 정보를 지우거나 분리 보관하는 코드가 있나?
- **CO7 업종별 표시 의무** — 예: 부동산 중개 광고는 중개사무소·개업공인중개사 정보와 매물의 소재지·면적·가격 등 명시 사항을 표시해야 하고, 중개보조원 정보는 표시하면 안 된다(공인중개사법, 국토교통부 '중개대상물의 표시·광고 명시사항 세부기준'). 매물·상품 데이터의 필수 칸이 비어도 게시되는지 코드에서 본다. 다른 업종이면 해당 법령을 "확인 필요"로.
- **CO8 남의 사진·글·데이터** — 다른 사이트에서 가져온 이미지·설명·데이터를 그대로 쓰나? (수집 기능이 있으면 데이터 수집 점검표로)
- **CO9 분석·광고 도구** — 방문 분석·광고 태그를 쓰는데 처리방침에 빠져 있지 않나?
- **CO10 약관과 실제 동작** — 약관의 환불·취소·해지 설명이 실제 코드 동작(환불 기간, 자동 결제 해지 방법)과 맞나? 구독이면 무료에서 유료로 넘어가거나 요금이 오를 때 따로 동의를 받나? 해지가 가입보다 훨씬 어렵지 않나?
